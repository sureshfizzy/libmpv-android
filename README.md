# libmpv for Android

A fork of [libmpv-android](https://github.com/jarnedemeulemeester/libmpv-android).

## Usage

```kotlin
implementation("org.jellycine.mpv:libmpv:1.0.1")
```

## Building from source

Take a look at [README.md](buildscripts/README.md) inside the `buildscripts` directory.
